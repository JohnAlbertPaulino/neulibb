# **App Name**: CampusFlow

## Core Features:

- Institutional Google Authentication: Secure user login and registration, restricted to institutional email addresses (e.g., @neu.edu.ph), leveraging existing Google accounts.
- Unified Visitor Self-Service Check-in: A streamlined portal for visitors to input their 'College Department' and 'Reason for Visit' for either the Library or Dean's Office, with automatic timestamping and institutional email verification.
- Real-time Admin Dashboard: A dynamic dashboard providing administrators with live visitor statistics, including total visitor counts filterable by day, week, and month across different facilities.
- Visitor Log & Status Management: A dedicated view for staff (Dean's Office/Secretary) to track and update visitor statuses (e.g., 'Waiting', 'In-Meeting', 'Completed') and review time-in/time-out details for appointments.
- User Account Management: Admin functionality to search for specific users by name and manage their access, including the ability to block or unblock accounts.
- AI-Driven Analytics Tool: A generative AI tool to provide comprehensive insights and summary reports for admins, identifying busiest hours, common visit reasons, and visitor trends to inform operational decisions.

## Style Guidelines:

- Primary color: A vibrant orange (#F29014), evoking energy and a welcoming, professional academic environment.
- Background color: A subtle, light off-white (#F8F6F3), offering a clean and academic canvas that promotes readability.
- Accent color: A deep, rich red (#8A1C17), providing strong contrast for alerts or key interactive elements while maintaining a professional feel.
- Body and headline font: 'Inter', a neutral and objective sans-serif, chosen for its excellent readability and modern, professional appearance suitable for institutional data and text.
- Use clean, minimalist line icons that clearly communicate functionality, enhancing the professional and data-focused nature of the application.
- A clear, card-based layout structure with distinct sections for different functionalities, ensuring an intuitive flow and adaptable design across various screen sizes for both web and mobile access.
- Subtle, fluid animations and transition effects, providing user feedback without causing distraction, enhancing the overall user experience during navigation and data interactions.
